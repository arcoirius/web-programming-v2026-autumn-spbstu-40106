# Лабораторная работа 2

## Задание

Вариант 15. Реализовать функцию `timeAgo`, которая принимает прошедшую дату типа
`Date` и возвращает строку с количеством прошедших минут, часов или дней с
корректной формой слова на русском языке.

Пример: `5 минут назад`.

## Реализация

Решение находится в файле `solution.js`.

Функция `timeAgo` вычисляет разницу между текущим временем и переданной датой. В
зависимости от величины разницы результат представляется в целых минутах, часах
или днях.

Для выбора правильной формы слов используются варианты `минута`, `минуты`,
`минут`, `час`, `часа`, `часов`, `день`, `дня`, `дней`.

## Запуск

Файл `solution.js` является ES module и экспортирует функцию `timeAgo`.
